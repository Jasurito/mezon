# Локальные модели и AI

## Зачем нужны модели

В проекте две роли моделей:

- **Языковая модель.** Это AI-наставник и NPC (судья, оппонент и другие).
- **Модель эмбеддингов.** Она превращает статьи и вопросы в векторы для смыслового поиска.

Модели не обязательны. Без них всё работает:

- наставник показывает найденные статьи;
- NPC отвечают заготовками;
- поиск идёт по тексту (полнотекстовый).

Модели можно запускать локально через Ollama (бесплатно) или использовать Claude Haiku 5.5 через ключ Anthropic.

## Вариант 1. Локально через Ollama

### Установка

macOS:

```bash
brew install ollama
```

Либо скачайте приложение с сайта ollama.com. Linux: установите Ollama по инструкции на ollama.com.

### Запуск

Если вы поставили приложение, просто откройте его. Иначе запустите сервер в отдельном терминале:

```bash
ollama serve
```

Ollama слушает адрес `http://localhost:11434`.

### Скачивание моделей

```bash
ollama pull gemma3:12b
ollama pull bge-m3
```

- `gemma3:12b` (около 8 ГБ): языковая модель.
- `bge-m3` (около 1,2 ГБ): эмбеддинги.

Проверьте, что обе модели на месте:

```bash
ollama list
```

Если модель не скачивается, часто виновата старая Ollama. Обновите её и повторите:

```bash
brew upgrade ollama
```

### Настройки в `.env`

Откройте `.env` (его вы создали из `.env.example`) и задайте:

```bash
LLM_PROVIDER=ollama
OLLAMA_MODEL=gemma3:12b
EMBEDDER=ollama-bge-m3
RAG_MAX_SOURCES=4
```

Что означают переменные и какие значения по умолчанию:

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `LLM_PROVIDER` | Провайдер языковой модели: `anthropic` или `ollama` | `anthropic` |
| `OLLAMA_URL` | Адрес Ollama. Для бэкенда в docker: `http://host.docker.internal:11434` | `http://localhost:11434` |
| `OLLAMA_MODEL` | Какая модель Ollama отвечает | `gemma3:12b` |
| `OLLAMA_MENTOR_TIMEOUT` | Таймаут ответа наставника, секунды | `60` |
| `OLLAMA_FAST_TIMEOUT` | Таймаут быстрых вызовов, секунды | `15` |
| `EMBEDDER` | Модель эмбеддингов. Пусто: смысловой поиск выключен. Для Ollama: `ollama-bge-m3` | пусто |
| `RAG_MAX_SOURCES` | Сколько статей уходит наставнику. Для локальной модели советуем `4`: меньше контекст, быстрее ответ | `8` |
| `RERANKER` | Переранжирование найденных статей: `none` или `llm`. `llm` добавляет один вызов модели, на локальной модели это заметно дольше | `none` |
| `RERANK_CANDIDATES` | Сколько кандидатов отдаётся reranker'у | `15` |
| `RERANK_TIMEOUT` | Таймаут reranker'а. Пусто: берётся таймаут быстрой модели | пусто |

После изменения `.env` перезапустите бэкенд.

Векторы для законов считаются при загрузке. Если вы включили `EMBEDDER` позже, загрузите законы заново:

```bash
make demo-laws
```

## Вариант 2. Claude Haiku 5.5 через ключ Anthropic

Ключ не нужен, если вы используете Ollama. Чтобы использовать Claude:

1. Получите ключ в консоли console.anthropic.com. Нужен положительный баланс на счёте.
2. Впишите его в `.env`:

```bash
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=ваш-ключ
LLM_MODEL_MENTOR=claude-haiku-5-5
LLM_MODEL_FAST=claude-haiku-5-5
```

Ключ хранится только в `.env`. Этот файл в `.gitignore` и не попадает в git. Никому не отправляйте ключ и не вставляйте его в чаты и код.

Ориентир по цене: порядка 0,1 цента за ответ наставника (это оценка, а не точная цифра; смотрите актуальные цены в консоли Anthropic).

Таймауты для Claude: `LLM_MENTOR_TIMEOUT` (по умолчанию 20 секунд) и `LLM_FAST_TIMEOUT` (по умолчанию 4 секунды). Уровень усилия наставника: `LLM_MENTOR_EFFORT` (по умолчанию `medium`).

Эмбеддинги при этом всё равно считаются локально через Ollama (`EMBEDDER=ollama-bge-m3`), если вы хотите смысловой поиск.

## Если компьютер слабее (8 ГБ памяти)

- Поставьте модель поменьше, например `llama3.1:8b`:

```bash
ollama pull llama3.1:8b
```

и укажите её в `.env`: `OLLAMA_MODEL=llama3.1:8b`. По-узбекски она пишет хуже, чем `gemma3:12b`.

- Или используйте Claude Haiku 5.5 (вариант 2): тогда модель работает не на вашем компьютере.
- Или работайте без AI.

## Сменили модель эмбеддингов: пересчитайте векторы

Векторы разных моделей несовместимы. Если вы поменяли `EMBEDDER`, пересчитайте их:

```bash
make ingest ARGS="run --reembed"
```

Для демо-базы используйте ту же команду с адресом базы:

```bash
DATABASE_URL=postgresql+psycopg://adolat:adolat@localhost:5433/adolat_demo \
  make ingest ARGS="run --draft-activate --reembed"
```

Подробности: [INGESTION.md](INGESTION.md).

## Освободить память

Ollama держит модель в памяти после ответа. Если компьютер тормозит:

```bash
ollama stop gemma3:12b
```
